---
name: Приоритет прототипных спецификаций
description: Как разрешать внутреннее противоречие TASK v2.3 по пакетам без визуала.
---

При внутреннем противоречии `TASK_REPLIT_UI_PROTOTYPE` v2.3 по `NOT_REQUIRED` применять более новую `DELTA_REPLIT` v1.0 и решение VISUAL-001: пакет без визуала может быть готов, если сервер вернул `visual_not_required = true`.

**Why:** §10 задания фиксирует новое решение VISUAL-001, а §11 содержит оставшуюся формулировку старой нормы о безусловной блокировке. DELTA прямо требует показать готовый и заблокированный варианты.

**How to apply:** интерфейс всегда показывает серверные `ready_for_review`, `blocking_reasons` и `visual_not_required`, ничего не вычисляя локально.
